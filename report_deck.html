Research Agent

Plan → Tool 选择 → 信号生成

1. Plan

基于 belief 制定分析计划
LLM 阅读 background_information 后，规划：关注哪些线索、需要验证哪些标的、计划调用哪些工具。
↓

2. Tool Selection

每步选择下一个工具
LLM 根据当前已有信息，从工具清单中选择最合适的工具（如 price_info、company_financial_info 等），直到信息足够或达到最大步数。
↓

3. Call Tool

调用工具并积累观测
执行工具调用，把结果追加到 tool_call_context；然后回到 Tool Selection，形成 ReAct 循环。
↓

4. Write Result

输出 1~5 条结构化信号
整合背景与工具观测，生成 action、symbol_code、symbol_name、risk_profile、evidence_list、limitations、probability。

llm 与 llm_thinking 分工

  • llm（非思考模式）：Plan、Tool Selection、单次工具参数解析
  • llm_thinking（思考模式）：Write Result，生成最终投资信号与结构化输出
  • 若 llm_thinking 未配置，Write Result 会回退到 llm

可调用的工具清单

  • stock_symbol_search_akshare / _us：股票搜索
  • price_info_akshare / _us：历史价格与行情
  • company_financial_info：公司财务概况
  • stock_summary：个股多维综合画像
  • stock_selector_akshare：按指标筛选 A 股
  • search_web：联网搜索补充事件

Research Agent 角色设计

4 个 Research Agent，每人对应一种风险偏好

风险偏好者

Agent 0
  • 追求短期高爆发
  • 关注政策、订单、题材、资金异动
  • 持仓周期：1 个交易日

稳健投资者

Agent 1
  • 偏好大盘蓝筹与高确定性
  • 关注龙头、业绩、分红回购、重大合同
  • 持仓周期：5 个交易日

激进套利者

Agent 2
  • 快进快出的事件驱动
  • 关注重组预期、龙虎榜、游资动向
  • 持仓周期：1 个交易日

防御套利者

Agent 3
  • 重视安全边际的防守型套利
  • 关注回购、业绩预增、机构抱团
  • 持仓周期：3 个交易日

所有 Agent 共享同一份 background_information，但各自基于自身信念独立选股、调用工具深挖、输出 1-5 个信号。
